# Visual System

## Canvas and colors

- Canvas: 16:9 widescreen, 13.333 × 7.5 inch
- Background: #FFFFFF
- Primary text: #000000
- Chinese font: Microsoft YaHei / 微软雅黑

## Typography

- Title: 28–30 pt, bold, top-left aligned
- Body: 14–16 pt
- Caption: 12 pt
- Alignment: primarily left aligned
- Text density: medium-high to high
- Decoration: minimal
- Visible sources: none
- Footer: none
- Page number: none
- Speaker notes: source evidence required

## Safe geometry

- Safe left margin: 0.40–0.55 in
- Safe right margin: 0.40–0.55 in
- Title Y: 0.15–0.30 in
- Body start: 1.00–1.15 in
- Bottom safe margin: >= 0.30 in
- Two-column gap: 0.25–0.40 in

## Standard title box

- x = 0.50
- y = 0.20
- w = 12.25
- h = 0.65
- font = Microsoft YaHei
- size = 30 pt
- bold = true
- color = #000000

标题过长时可降到 28 pt。

这些坐标属于 soft constraints，允许根据内容在约 ±0.2–0.4 inch 内调整。
