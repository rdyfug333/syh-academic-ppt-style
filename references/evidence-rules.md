# Evidence Rules

Source evidence must remain traceable.

Do not invent:

- experimental settings
- numerical values
- interpretation
- causal claims
- missing parameters
- missing equations
- missing experimental conclusions

## Figure rule

Original paper figure > redraw

尤其不要重新绘制：

- experimental results
- architecture
- circuit
- multi-panel figures
- algorithm figures
- complex technical diagrams

Codex 主要负责：

- crop
- scale
- arrange

不要为了“现代化”而重画论文 Figure。

## Table rule

Preserve original values.

Do not silently correct anomalies.

允许：

- 裁关键行
- 裁关键列
- 放大原表
- 用简单黑色表格线忠实重建

禁止：

- 自动修改数据
- 自动修异常值
- 自动排序
- 无必要地把 Table 改成彩色图表

## Formula rule

Editable equation

>

High-quality original equation crop

>

Manual approximation

但：

Mathematical correctness

>

Editability

复杂公式若重建容易出错，优先使用论文原式。

## Speaker notes

每页 speaker notes 建议包含：

- Source: Paper page / section / equation / figure / table
- Evidence: What claims are directly supported
- Presenter note: Additional explanation
- Verification: Any unresolved ambiguity or source conflict

这些信息不得显示在主幻灯片正文。
